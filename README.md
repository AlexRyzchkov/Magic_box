# Magic_box

## О чём этот проект?
Этот проект помогает понять, что такое кортеж в Python, используя простую и понятную аналогию - волшебную коробку, которую нельзя открыть и изменить после того, как она закрылась.

## Цель проекта: 
Показать главное отличие между кортежем и списком на живых примерах и короткой игре.
